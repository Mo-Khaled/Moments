# Moments

Shopify theme for MOMENTS (momentseg.com), in English and Arabic (RTL).

- `sections/`, `snippets/`, `blocks/`, `templates/`, `assets/`, `locales/`, `config/`, `layout/`: the theme
- `scripts/`: push, checks and store tooling (`bash scripts/push.sh --only <file>` pushes to the live theme)
- `data/`: fragrance notes and the scent glossary behind the filters and the product scent guide
- `translations/`: Arabic translation batches imported through Shopify admin
- `docs/`: design notes, audits and performance reports
