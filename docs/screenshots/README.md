# Screenshots

Screenshots are generated by the scripts in ../../scripts/ and are not kept in git (they were 168 MB). Run the matching script to regenerate:

| Folder (git-ignored) | Script |
|---|---|
| colour-flow/ | scripts/check-colour-flow.mjs, scripts/audit-seams.mjs |
| cards/ | scripts/check-card-layout.mjs --shots, shot-card-iphone.mjs |
| mobile-menu/ | scripts/check-mobile-menu.mjs --shots <tag> |
| bundle/ | scripts/check-bundle.mjs |

`moment-marks.png` is the one reference image kept: the six Moment marks at 24, 48 and 96 px (scripts/shot-marks.mjs).
Earlier phases (hero, tiles, tickers, cleanup, identity reset) are in git history before the cleanup commit.
